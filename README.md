# Bootcamp

Proyecto final Dashboard Interactivo  

Reporte dinámico en **Power BI** sobre **seguridad y criminalidad en Colombia (2023-2024)**.  

El tablero incluye:  
- **Tendencias anuales y mensuales** de homicidios y hurtos a personas.  
- **Mapas geográficos interactivos** con concentración de delitos por municipio.  
- **Comparación entre años** para analizar variaciones.  
- **Distribución de víctimas y tipos de armas utilizadas** identificando la población más afectada y los medios más frecuentes
- **Tablas dinámicas** con filtros por departamento, municipio, género y tipo de delito.  

Este dashboard permite identificar **patrones delictivos**, analizar la **evolución temporal** y reconocer las **zonas de mayor incidencia**, apoyando la toma de decisiones en temas de seguridad.
